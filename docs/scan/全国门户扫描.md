# 全国 333 个地级单位门户扫描

日期：2026-11-11　方法：`tools/scan/national.py`　耗时：75 秒

城市清单来自民政部行政区划（342 条，剔除「市辖区/县」后 **333** 个地级单位），
候选域名 = 全名拼音 / 首字母缩写 / 人工覆盖表，命中判据 = 首页标题或正文含该地名。

## 结果（三段式）

| 阶段 | 手段 | 可达 | 占比 |
|---|---|---|---|
| 1 | 拼音猜域名 + 人工覆盖表 | 235 | 71% |
| 2 | + 省级门户→地市导航发现 | 270 | 81% |
| 3 | + Chromium 真实浏览器重试 | **289** | **87%** |

最终：可达 289 / 低质 24 / 不通 20（另有部分 412、521 硬拦）。

阶段 3 修复的 19 个，全部是「httpx 403 但浏览器能过」——说明多数 403 是 UA/指纹策略，不是真拒绝。
**成都 412、合肥 521 浏览器仍解不了**，属挑战式 WAF。

省份维度最差：青海 2/8、新疆 6/14、云南 7/16、湖南 7/14、吉林 5/9。

## 三类失败与解法

### A. 反爬拦截（约 40 个）

| 现象 | 例子 | 判断 |
|---|---|---|
| 412 / 405 + 完整浏览器头仍拒 | 唐山 | WAF，需真实浏览器上下文 |
| 521 | 合肥 | 源站不可用或 CDN 拒绝 |
| 403 | 南京、常州、蚌埠、六安 | **实为 UA 策略**：Chromium 全部通过 |

**解法**：Playwright 带真实指纹；仍失败的记为 blocked，不硬闯。

### B. 域名不符合拼音规则（约 45 个）

| 城市 | 拼音猜测 | 真实 |
|---|---|---|
| 哈尔滨 | haerbin ✗ | **harbin** ✓ |
| 长治 | zhangzhi ✗（多音字） | **changzhi** ✓ |
| 六安 | liuan ✗（多音字） | **luan** ✓ |
| 呼和浩特 | huhehaote ✗ | hhht 亦不通，待查 |

**解法**：省级门户 → 地市链接做权威发现；覆盖表只做兜底。

### C. 单页应用壳（约 13 个）

200 但只有 642 字节（南京即是），内容靠 JS 渲染。

**解法**：Playwright 渲染后取 `innerText` —— 与成都 412 不同，这类是**能解的**。

## 结论

1. **纯拼音猜测天花板约 71%**。再往上必须换发现方式：省级门户 → 地市链接。
2. 「所有城市」要分层，不能一刀切：

| 层 | 范围 | 状态 |
|---|---|---|
| L0 登记 | 333 城 | ✅ 已完成 |
| L1 抓取 | 235 城（补完约 300） | 入口待补齐 |
| L2 判定 | 20–30 城 | 每城需人工确认规则 |
| L3 动作 | 3 城 | 需 mock 办理服务 |

3. **L2 不可能覆盖 333 城**，不是技术限制，是每条政策都要人确认「什么算符合」。这一点必须写进 README 的范围声明。

## 硬拦站点的根因（2026-11-11 实测）

20 个 403/412/521 的站点，逐个看响应头与首屏脚本，只有三类：

| WAF | 指纹 | 代表站 |
|---|---|---|
| 加速乐 | `__jsluid_s` + 521 + 内联 `document.cookie=__jsl_clearance` | 合肥、梅州 |
| CT2-WAAP | `server: CT2-WAAP`、标题 `Environment Checking`、加载 `ctct_bundle_*.js` | 黄山 |
| 瑞数 | `server: ******`、随机名 cookie（`azSsQE5NvspcO`）、加载 `/4pUrbNyi8V8b/*.js` | 成都、兰州 |

**关键发现：它们不是"拒绝访问"，而是"两段式挑战"。**
首包回 412/521 + 一段混淆 JS；JS 执行后写入 cookie；**必须再请求一次**才返回正文。
用 `curl` 永远拿不到，用浏览器只请求一次也拿不到——这就是之前 289 卡住的原因。

改成"同一 URL 试两次 + 判据看正文不看状态码"后：合肥 3,254 字、梅州 1,421 字、
**成都/兰州从 0 字恢复为可读正文**。

（成都首包 → 挑战 JS 200 → 带 cookie 二次请求 → 400 的路径也观测到了，
说明瑞数的令牌与浏览器指纹绑定，无头模式首次不一定过，但重试能过。）

## 第二跳：省门户自身也要渲染

吉林 / 江苏 / 湖南 / 甘肃 / 青海 的省级门户，httpx 拿不到地市链接——
不是没有导航，是导航由 JS 渲染。用浏览器渲染后重新匹配，补回 14 个：
吉林 4/4、江西 3/3、新疆 2/2、山西/江苏/安徽/河南/西藏 各 1。

## 最终

| 阶段 | 可达 | 占比 |
|---|---|---|
| 拼音猜域名 | 235 | 71% |
| + 省门户导航（httpx） | 270 | 81% |
| + 浏览器重试（单次、看状态码） | 289 | 87% |
| + 两段式挑战 + 内容判据 | 295 | 89% |
| + 省门户浏览器渲染 | **309** | **93%** |

剩余 24 个：广西/甘肃/青海 的省门户自身也被拦，导航取不到；其余是域名非常规的自治州。
这些记为 `blocked`，系统对它们明确返回"未覆盖"——**覆盖缺口本身要被记录，而不是猜一个域名填上**。
