# 边界抽检：条款到底切没切对

结构不变量（见 `docs/SEGMENTATION.md`）能证明条款**自洽**，但证明不了它**切对了**。
这一份是人工抽检的记录：四批样本、每批 20 条、逐条判上边界与下边界。

抽检工具：`tools/eval_boundary.py --seed N --out eval/boundary_sheet_X.md`
每条给出四段上下文——上一行末尾 / 本条开头 / 本条结尾 / 下一行开头——只看这四段判：

- **上边界**：这一条是不是从该开始的地方开始（有没有把上一句尾巴吞进来、有没有从半句话开始）
- **下边界**：这一条是不是在该结束的地方结束（有没有把下一节/落款/附件区吞进来）

判的人是我（模型），不是人工标注者，这是这份报告最大的局限，见文末。

## 4. 数字怎么读

- 20 条样本的 95% 置信区间（Wilson）：19/20 → **75%–99%**；20/20 → **84%–100%**。
  也就是说"每批 20 条"只能分辨"有明显问题"和"看不出来"，分辨不了 95% 与 99%。
- 四批之间不是同一批题，所以**不能**做配对检验，只能看缺陷类别是否在减少：
  第一批 2 类、第二批 3 类、第三批 1 类、第四批 1 类（且是全新的类）。
  这符合"抽检不断发现新缺陷"的正常形态——不是收敛到零，而是新类别越来越少。

## 5. 还没解决的

1. **附件里的表单被当条款**。`沪人社规〔2020〕17号` 的《以工代训补贴发放审批表》是一张表，行文本被当正文切。表格类附件目前只能做到"一行一块"，做不到"这不是正文"。
2. **path 重复**：206 份文档里有 6,293 条条款的 `path` 完全相同（同一份文件里出现两次「一、」）。不影响引用（引用带页码/偏移），但影响"按 path 去重"的任何逻辑。
3. **没有第二个人判**。这批判定全部来自我；`docs/SEGMENTATION.md` 里说的"人工复核"目前是我自己复核自己。

## 6. 对面试怎么讲

一句话：**结构不变量证明自洽，人工抽检证明切对，两者都要，且都不能互相替代。**

追问「你这 80 条够吗」——不够，20 条一批的区间是 84%–100%，只能说明没有系统性问题；真正的做法是把抽检固化成每次解析器改动后的回归（`--seed` 固定四批），而不是一次性体检。
