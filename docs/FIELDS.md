# 一条记录保留什么，每样从哪来

> 这份文档回答两个问题：**存什么**、**每个字段怎么拿到**。
> 判断标准只有一条：这个字段能不能改变下游的某个决定（能不能引用、能不能判有效期、能不能判覆盖）。

---

## 0. 四层保留物

| 层 | 位置 | 是什么 | 能否重生成 |
|---|---|---|---|
| **字节层** | `data/raw/<sha前12>/` | 原件字节（HTML/PDF/DOC），按内容哈希分目录 | ❌ **不可再生**，是证据 |
| **记录层** | `data/processed/<文号>.json` | 一份文件一条记录：字段 + 块 + 条款 | ✅ 可由字节重算 |
| **索引层** | `data/index/clauses.jsonl` | 叶子条款 + 引用偏移，供 BM25 | ✅ 可由记录重算 |
| **登记层** | `data/registry/*.jsonl` | 全量清单、抓取状态、孤儿 | ✅ 可由记录+日志重算 |

规矩：**下层可弃，上层不可弃**。删索引不心疼，删 `raw/` 就是毁证据。

## 1. 字段清单

### A. 身份（这份文件是谁）

| 字段 | 含义 | 来源 | 覆盖率 |
|---|---|---|---|
| `doc_no` | 文号，**唯一键** | 列表页 / 人工 fixture / 正文正则 | 100% |
| `doc_no_source` | 文号从哪来 | `list` / `manual` / `text` | 100% |
| `title` | 标题 | 列表页 → 详情页 `h1` → PDF 版头 | 100% |
| `url` | 详情页地址（只作索引，不是内容） | 抓取时 | 100% |
| `agency` | 发文机关 | **未存**（可从版头/落款补） | 0% |

### B. 时间（四个日期，各是各的）

| 字段 | 含义 | 来源 | 覆盖率 |
|---|---|---|---|
| `issued_at` | **成文日期**（落款） | ①落款 ②列表页 ③详情页发布时间 | 78% |
| `issued_at_source` | 落款怎么来的 | `sign_block` / `sign_inline` / `list` / `manual` / `unknown` | 100% |
| `published_at` | **印发/发布日期** | 列表页「生成日期」/ 详情页「发布时间」 | 51% |
| `effective_from` | 施行日期 | 正文「自 X 起施行/实施/执行/生效」 | 59% |
| `effective_to` | **有效期至** | ①列表页列 ②正文「有效期至 X」③`long_term` | 63% |
| `effective_to_source` | 有效期怎么来的 | `list` / `text` / `long_term` / `unknown` | 100% |
| `issued_year` | 只有年份（兜底） | 文号里的 `〔2022〕` | 99% |
| `date_precision` | 精度 | `day` / `year` / `unknown` | 100% |
| `date_note` | 冲突与缺口的说明 | 计算得出 | 76% |

**规矩**：抽不到写 `None` + `unknown`，**不许猜、不许默认长期有效**；两个日期冲突时**都留**，不互相覆盖。

### C. 来源与凭证（凭什么信它）

| 字段 | 含义 | 来源 | 覆盖率 |
|---|---|---|---|
| `retrieved_via` | 怎么拿到的 | `crawl` / `manual:official` / `manual:mirror` | 100% |
| `fetched_at` | 抓取时刻 | 抓取时 | 100% |
| `page_sha256` | 页面字节哈希 | 计算 | 100% |
| `page_kind` | 载体 | `html` / `pdf` | 100% |
| `attachments[]` | 附件清单 | 详情页链接 / PDF 内嵌 | 242 份有 |
| `attachments[].sha256/chars/extract/ocr_conf` | 附件凭证与抽取质量 | 解析 | — |

### D. 内容（正文与条款）

| 字段 | 含义 | 怎么产生 |
|---|---|---|
| `blocks[]` | 格式解码后的文本块（`i/kind/page/text`） | HTML/PDF/DOCX 各自的解析器 |
| `clauses[]` | 按编号归组的条款（`path/label/level/start/end/page`） | `split_clauses()` |
| `stats` | 块数、字数、条款数、按层级分布 | 计算 |

### E. 质量（这份记录可信到什么程度）

| 字段 | 含义 | 取值 |
|---|---|---|
| `parser_version` | 解析器版本，**引用偏移只在同版本内有效** | `0.3.1` |
| `extract` | 正文抽取方式 | `native` / `ocr` / `textutil` / `unsupported` |
| `ocr_conf` | OCR 置信度 | 0–1 |
| `doc_status`（待加） | 登记状态 | `ingested` / `listed_only` / `fetch_failed` / `parse_failed` |

## 2. 五条获取通道

| 通道 | 拿到的字段 | 实现 | 局限 |
|---|---|---|---|
| **① 列表页表格** | 文号、标题、印发日期、有效期 | `tools/watch/watch.py` `parse_rows()` | 只有上海人社这一种表结构；一半行没有日期 |
| **② 详情页正文** | 标题、落款、施行日、有效期 | `parse_html` + `dates.py` | HTML 详情页**没有版头**，文号抽不到 |
| **③ 详情页字段** | `发布时间` | **未实现**（截图里能看到 `发布时间：2014-09-18`） | — |
| **④ PDF 版头/落款** | 机关、文号、标题、落款 | `parse_pdf` + `dates.py` | 长附件时落款不在末尾窗口 |
| **⑤ 人工 fixture** | 任意 | `data/fixtures/manual_adds.json` | 靠人，必须带证据 URL |

**优先级**：① > ③ > ④ > ② > ⑤（人工只在"官方站确实取不到"时用，且必须标 `manual:official|mirror`）。

## 3. 明确**不保留**的东西

| 不存 | 为什么 |
|---|---|
| 文件名 | 是流水号（`t0035_1390708.html`），没有语义；语义在 `title` |
| HTTP 响应头 | 只留 `http_status`（失败时进登记层），其余无判定价值 |
| 页面渲染后的截图 | 体积大、不可检索；**需要给人看时按需渲染**（`tools/report/shots.py`） |
| 摘要、结论、答案 | 派生量，每次重算；存了会掩盖模型换代 |
| 城市/时间分目录 | 引用会随目录变动而失效；只用内容哈希 |

## 4. 当前覆盖率与目标

| 字段 | 现在 | 目标 | 差距怎么补 |
|---|---:|---:|---|
| `doc_no` / `title` / `url` / `sha256` | 100% | 100% | — |
| `issued_at`（天级） | 78% | 90% | ③详情页发布时间 + ④扫描窗口到附件为止 |
| `published_at` | 51% | 90% | ③详情页发布时间 |
| `effective_to`（已知或显式 unknown） | 100% | 100% | 已达（63% 有值 + 37% 显式 unknown） |
| `agency` | 0% | 90% | 版头/落款机关名抽取 |
| `doc_status` | 未字段化 | 100% | 已算在 `data/registry/docs.jsonl`，并入记录 |

## 5. 判断标准（写给自己看的）

一个字段该不该留，问三句：

1. **它能不能改变某个下游决定？**（能不能引用、能不能判过期、能不能判覆盖）
2. **它能不能重算出来？** 能重算的别存（或者只存够重算的输入）。
3. **它错了会不会安静地错下去？** 会的话，必须配 `*_source` 和显式的 `unknown`。
