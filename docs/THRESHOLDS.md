# 判据与常数

这份文档回答一个问题：**系统凭什么决定"答"还是"不答"，这些数字从哪来。**
原则：判据只有一套；每个数字都要能被单独消融复现（`python -m tools.gate_ablation`）。

## 一、判据只有一条

```
答 = confidence.score(lex, margin, cos) >= 0.38

lex    = min(top1 分 / 12, 1)          # 词对上了多少
margin = min(max(分差, 0) / 4, 1)      # 领先第二名多少
cos    = clamp((余弦 - 0.55) / 0.35)   # 意思对上了多少
score  = 0.40·lex + 0.25·margin + 0.35·cos
```

这是唯一参与"答不答"的规则，代码在 `app/retrieval/confidence.py`。
0.38 不是概率，是 dev 上选出的工作点；换语料或换模型要重选。

## 二、消融：每一项拿掉会怎样

dev official n=103（另有 2 题在判据前就被拦掉）＋ 域内无政策 9 ＋ 域外 1：

| 配置 | 作答 | 答对 | 精度 | 无政策误答 |
|---|---|---|---|---|
| **0.40/0.25/0.35，t=0.38（现行）** | 93 | 69 | 74% | **0** |
| 去掉 lex | 70 | 51 | 73% | 1 |
| 去掉 margin | 102 | 73 | 72% | **4** |
| 去掉 cos | 87 | 64 | 74% | 2 |
| 只用词面（lex+margin） | 96 | 71 | 74% | 2 |
| 只用余弦 | 94 | 69 | 73% | 2 |

- **lex 是主承重**：去掉后少答 23 题、少答对 18 题——政策问答里关键词信号仍然最强。
- **margin 是红线的守卫**：去掉后多答对 4 题，但"域内无政策"误答从 0 变 4。它买的不是准度，是"不瞎答"。
- **cos 是准度贡献**：去掉少答对 5 题，且误答 +2。
- 三者缺一，都无法同时保持 0 误答——**现行组合是唯一零误答的配置**。

阈值扫描（同组权重）：

| 阈值 | 作答 | 答对 | 无政策误答 |
|---|---|---|---|
| 0.30 | 101 | 73 | 5 |
| 0.34 | 97 | 72 | 2 |
| **0.38** | 93 | 69 | **0** |
| 0.42 | 89 | 66 | 0 |
| 0.46 | 82 | 60 | 0 |

0.34 能多答对 3 题，代价是 2 条误答；我们选了 0.38，因为"不该答的不答"是硬约束。

## 三、删掉或降级的常数

| 常数 | 处置 | 依据 |
|---|---|---|
| `MIN_SCORE 3.0` | 保留为**性能参数** | 取 0 与 3.0，作答/答对/误答完全相同 |
| `MIN_SCORE_STRONG 5.3`、`MIN_MARGIN_STRONG 1.25` | **降级模式专用** | 语义模型可用时走不到这段代码；仅 CI 无模型时兜底 |
| `MIN_COVERAGE 0.5` | 只用于展示分档 | 不参与拒答 |
| `MIN_ANSWER 0.0`、`MIN_CAND_COV 0.0` | 停用 | 值为 0 等于关闭 |
| `CLAUSELEDGER_STRONG3` | **删除** | dev 无收益；负样本多 1 条误答 |
| 余弦准出 `gate.py`（0.68/0.70/0.72） | **删除** | 四个阈值全部不如组合判据，见 `EVAL-SPEC.md` §6.6 |

## 四、结构参数（不是判据）

这些决定"给多少、怎么排"，不决定"答不答"：

| 参数 | 值 | 位置 |
|---|---|---|
| RRF k | 60 | `app/retrieval/dense.py` |
| 锚点文件数 | 3 | `app/answer/context.py` |
| 每份文件展开条款数 | 20 | 同上（`CLAUSELEDGER_ASM_PER_DOC`） |
| 上下文预算 | 12,000 字 | 同上 |
| 单条上限 | 1,200 字 | 同上 |
| 标题命中权重 | 0.6 | `app/retrieval/search.py::rank_candidates` |

它们有实测支撑（`per_doc` 3/5/8/20 → 上下文覆盖 67.1/68.6/70.0/72.9），但属于资源分配，不参与判断题。

## 五、再加一个常数之前

1. 先写清它要救哪个具体失败（题号 + 现象）；
2. 跑 `python -m tools.gate_ablation`（或等价消融），给出"加/不加"的对照；
3. 如果它只影响一个 split、或让任何一条硬约束变差，就不加；
4. 加完更新本文档的表格与出处。
