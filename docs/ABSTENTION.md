# 拒答：从"词覆盖率"换成"检索分 + 三态输出"

> 一句话：**覆盖率量的是"问句写得笼不笼统"，不是"证据够不够"。** 我们把它从判据降成展示，
> 改用检索分决定"敢不敢下结论"，并把"查到候选但没有答案"单列成第三态。

## 1. 问题

政策问答里最贵的错误不是答错，是**假装有答案**。我们没有生成模型，所以"让模型自评"这条路
走不通；最初的替代品是词覆盖率：

```
cov = |提问词 ∩ 首条条款词| / |提问词|
cov < 0.5 → 拒答
```

## 2. 证据：这个指标方向是反的

2026-11-17 造了 12 条**在域内、语料确实没有**的问题（关键词在 574 份正文里 0 命中）：
博士后公寓、电子劳动合同、外国人工作许可、集体合同备案、育儿假、护理假、随军家属、
托育补贴、个人养老金、仲裁时效、选调生、2027 年最低工资。

| 组 | 覆盖率 |
|---|---|
| 该答的 9 条（旧闸门误拒的） | **0.38–0.45** |
| 该拒的 7 条（系统答错了的） | **0.50–0.67** |

原因：该答的题长而具体（分母大），该拒的题短而笼统（共享"合同/补贴/申请"这类通用词）。
**任何覆盖率阈值都会同时误伤前者、放过后者。**

换成"最长公共子串占比"也不行：正样本中位 0.30，负样本 0.20，但负样本 p90 = 0.38
高于正样本 p10 = 0.17，区间完全重叠。

## 3. 做法：三态输出 + 检索分门槛

| 条件 | 结局 | 行为 |
|---|---|---|
| 城市/部门/领域闸命中 | `not_covered` / `out_of_domain` | 检索前返回，`n_queries=0`，不留"查过"的痕迹 |
| 覆盖率 < 0.30 | `insufficient` | 一个字都对不上，拒答 |
| 首条检索分 < 6.0 | **`no_direct_clause`** | 给候选，但明说"可能不是你要的规定" |
| 其余 | `answer` | 正常作答 |

`no_direct_clause` 与拒答的区别：**拒答不返回条款，它返回候选**。与回答的区别：**它不下结论**。

## 4. 效果（dev 官方题 n=92）

| 指标 | 只按覆盖率（0.30 地板） | 现在 |
|---|---|---|
| hit@1（只算真作答的） | 61% | **59%（48–68）** |
| hit@3 | 84% | 79% |
| 作答率 | 100% | 88% |
| **已作答中的 hit@1** | 61% | **67%** |
| no_direct_clause | 0 | 11 条（其中 2 条金标就在候选第 1 名） |
| out_of_scope 误答 | 0/18 | **0/18** |

在域内无政策的 12 条上：**正确处理 5/12 → 11/12**（唯一漏网的是"电子劳动合同"，首条分 7.0 高于门槛）。

**取舍**：标题指标 hit@1 掉 2pp，换来"开口时更可信"（67% vs 61%）和 6 倍的无政策识别率。

## 5. 已知局限

- **6.0 不是校准出来的**：正样本 p10 = 5.79、中位 9.27；负样本 4.0–7.0（8 条）。样本只有 8 条负例，
  这个门槛是"看分布取的"，不是 conformal 或 risk-coverage 选点。
- 检索分是 **BM25 绝对分**，换语料/换分词就不成立，必须重新取。
- 真正的判据应该是语义信号（cross-encoder / 小模型），沙箱里模型下载失败，这一步没做成。

## 6. 复现

```bash
python -m tools.eval_missing      # 12 条在域内无政策的题
python -m tools.eval_v2 --split dev
python -m tools.ask "电子劳动合同有法律效力吗"
```


## 8. 2026-11-19：判据从"绝对分"改成"绝对分 + 分差"

原来的规则是 `首条分 < 6.0 → 不下结论`。这条规则在口语问句上系统性偏低：问句越长、词越散，
BM25 的绝对分越低，于是"该答的"和"该拒的"被同一条线切开——实测该答的 0.38–0.45 覆盖率、
该拒的 0.50–0.67 覆盖率，方向是反的。

改成两个条件**同时成立**才怯：

```python
margin = out[0].score - out[1].score
weak = out[0].score < 5.3 and margin < 1.25
```

理由：绝对分会随问句长度、改写扩展词整体平移，而**分差**对整体平移不敏感。
标定方式：dev（95 条有候选）上网格搜索 (a, b)，约束是"域内无政策 12 条最多错 1 条、
域外 18 条错 0 条"。

| 口径 | 旧规则 (s<6.0) | 新规则 (s<5.3 且 分差<1.25) |
|---|---|---|
| 官方 dev hit@1 | 61% | **63%** |
| 官方 dev 作答率 | 88% | **96%** |
| 已作答中 hit@1 | 69% | 66% |
| 口语 64 hit@1 | 42.2% | 42.2% |
| 域内无政策 12 条 | 11/12 正确 | 10/12 正确 |
| 域外 18 条 | 拒答 100% | 拒答 100% |

结论：**收益在"敢答"上（作答率 88%→96%），不在"答对"上**（hit@1 +2pp，n=92，落在噪声内）。
代价是负例上多错 1 条、已答中精度降 3pp。这是明确的取舍，不是纯改进。

同时确认两件事：

1. **cross-encoder 重排在端到端路径上仍然有害**（官方 63%→55%、口语 42.2%→35.9%），
   即使换了新判据。原因：重排把 BM25 分低但语义像的条款顶到第一，而后续的年份分层、
   标题加权、类型加分都是围绕 BM25 分设计的。默认保持关闭（`CLAUSELEDGER_RERANK=1` 才开）。
2. **LLM 改写（v3）在端到端上仍无增益**：官方 63%（与不加一样）、口语 40.6%（低于规则表的 42.2%）。
   默认保持 `rules`；`CLAUSELEDGER_REWRITE_BACKEND=llm` 才启用。

## §9 置信度：BM25 + 语义一起看（2026-11-20）

原来的判据只看 BM25 分与分差，于是重排/稠密把"语义对、用词不同"的条款顶到第一时，
判据反而说"不敢答"——越有效的语义层，越被自己的判据吃掉。

实测 AUC（top-1 是否正确，dev 114 + 口语 64）：

| 信号 | AUC |
|---|---|
| BM25 分 | 0.731 |
| 分差（top1 − top2） | 0.659 |
| 语义余弦（bge-small） | 0.704 |
| **三者加权** | **0.767** |

置信度 = 0.40·min(BM25/12,1) + 0.25·min(分差/4,1) + 0.35·(余弦−0.55)/0.35，阈值 **0.38**
（在 dev 上选，硬约束：域外 18 条、域内无政策 12 条一条都不能答）。

效果（严格命中口径）：

| 口径 | 旧判据（BM25+分差） | 新判据（+语义） |
|---|---|---|
| 官方 作答 / 精度 | 93 / 65% | 90 / 64% |
| 口语 作答 / 精度 | 37 / 62% | 32 / **66%** |
| 域内无政策 正确拒答 | 11/12 | **12/12** |
| 域外 正确拒答 | 18/18 | 18/18 |

代价：作答率降 3–7pp；收益：口语精度 +4pp、负样本清零。
模型不可用时自动退回旧判据（`CLAUSELEDGER_CONF=0` 可强制关闭）。

## 10. 覆盖率闸已证伪并关闭（2026-11-21）

**结论：词重叠覆盖率不能当置信判据，默认关闭（`MIN_ANSWER=0`、`MIN_CAND_COV=0`）。**
代码与参数保留，只为能复现当时的实验。

### 为什么

`cov = |提问实词 ∩ 条款词| / |提问实词|`。它测的是"词有没有出现"，不是"这句话回没回答问题"。

实测（dev 105 题，top-1 条款）：

| 口径 | 中位 | 分位 | 覆盖率 ≥0.5 的比例 |
|---|---|---|---|
| top-1 正确（n=72） | 0.71 | p10 = 0.50 | 66/72 |
| top-1 错误（n=31） | 0.60 | p90 = 0.89 | **22/31** |

错答案里 71% 覆盖率也过 0.5；AUC **0.483**（不如随机）。在"域内但无政策"的 12 条上方向还是反的
（错答 0.50–0.67，该答的长题只有 0.38–0.45）。

### 关掉之后（四组同测）

| 配置 | P@1 | 作答率 | 作答精度 | 无政策拒答 | 域外拒答 |
|---|---|---|---|---|---|
| 候选 0.25 / 地板 0.30 | 68.6% | 95% | 71% | 10/12 | 30/30 |
| **全关（现状）** | 68.6% | 95% | 71% | 9/12 | 29/30 |

代价是少 2 条正确拒答（1 条无政策、1 条域外），收益是不再误伤长题干与口语问法。
置信判据改用 BM25 分 + 分差 + 语义余弦（§9），覆盖率降级为**展示字段**，卡里写"词面重合"并注明不是置信度。

### 已知遗留

- 域外仍漏 1 条（`新能源汽车补贴政策` → 沪人社职发（2011）22号）：它共享"补贴"这个域词，
  且首条 BM25 分与余弦都高。修法方向是"要求提问里最稀缺的那个词也命中"，而不是把阈值调回去。
