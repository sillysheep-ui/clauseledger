# 落户判定：为什么这里是规则，不是检索

> 一句话：**72 分不是一段文字，是一张表。** 检索能告诉你"评分办法在第 21–26 页"，
> 但回答"我 63 分够不够"要做的是逐项求和——这是算术，不是找句子。

---

## 1. 规则从哪来

| 项 | 值 |
|---|---|
| 文件 | `沪教委学〔2026〕13号`《关于做好 2026 年非上海生源应届普通高校毕业生进沪就业工作的通知》 |
| 地址 | `https://www.shanghai.gov.cn/cmsres/c0/c0be2153e4e04371a7bd856e099f83fc/03cad02918ba513e483ac2037250f613.pdf` |
| 规模 | 52 页 / 34,238 字 / 105 条 |
| 评分办法 | **附件 4，第 21–26 页** |
| 标准分 | **72 分**（正文第 11 页） |

规则文件：`rules/sh/luohu-2026.yaml`。**人从 PDF 抄的，不是模型抽的**——每条带页码，
可以逐条回原文核对。抄写只保留"分值 + 条件"，解释性括注不抄（它们不是判据）。

## 2. 为什么不让 LLM 判

| 交给 LLM 的 | 不交给 LLM 的 |
|---|---|
| 把自述映射成字段（"我六级 520" → `foreign=cet6_or_tem8`） | 每项的分值 |
| 解释为什么差这几项 | 求和 |
| 提示还缺什么材料 | 够不够的结论 |

理由：分值、互斥、封顶都是**确定的**。让模型做算术，唯一的结果是偶尔算错，而且错得没法查。

## 3. 四态，不是三态

| 状态 | 含义 | 例子 |
|---|---|---|
| `satisfied` | 确定符合，得分 | 硕士 + 一类校 + 成绩一级… |
| `unsatisfied` | 确定不符合 | 学历是本科却按硕士项判 |
| `unknown` | **缺信息，判不了** | 没填学校类别 |
| `not_applicable` | 同组已取更高项，本项不适用 | 硕士项得分后，本科项不适用 |

**两条硬规矩**：

1. **unknown 不是 0 分**。缺信息时给的是区间 `[确定得分, 上限]`。
2. **只有在"上限都够不到 72"时，才允许说不满足**。否则一律说"判不了"。

## 4. 一个反直觉的发现

把硕士的基本要素全部拉满：

```
学位 24 + 一类校 15 + 在沪 2 + 成绩一级 8 + CET-6 8 + 计算机 7 = 64
+ 用人单位 7 = 71
```

**71 分，比 72 少 1 分。** 也就是说：硕士生把基本要素全部拿满，仍然不够，
必须再拿至少 1 分导向分（荣誉 / 竞赛 / 专利 / 西部计划）。

这不是我算错了，是规则本身如此——而这个结论只有把规则拆成数据才能得到，
纯检索永远发现不了。

## 5. 现在的边界（不装的）

| 没做 | 后果 | 处理 |
|---|---|---|
| 附录 1/3/4 高校名单未解析 | 学校类别必须由人给，否则 `unknown` | 写进 `meta.unresolved` |
| 附录 5 重点学科目录未解析 | `employer_key_field` 必须由人给 | 同上 |
| 居转户（7 年 + 职称）未建规则 | 只能检索到办法，不能判定 | 下一步 |
| 用人单位资质（注册地、纳税）未核 | `employer.*` 全依赖自述 | 需外部数据，暂缺 |
| 材料清单未做核查 | 不知道该带什么 | 下一步 |

## 6. 怎么验证它是对的

| 验证 | 做法 |
|---|---|
| 规则抄写没抄错 | 每条带页码，抽查 10 条回 PDF 核对 |
| 算术没算错 | 单测覆盖：直落、差 1 分、封顶、缺项、明显不够 |
| 边界没错 | 专门测"缺学历"必须 `unknown` 而不是 `unsatisfied` |

现有 8 条单测，`pytest tests/test_luohu.py`。

## 7. 面试官会问什么

| 问 | 答 |
|---|---|
| 「这跟写个 if-else 有什么区别？」 | 规则在 YAML 里，改政策改数据不改代码；每项带页码；四态 + 区间；同组互斥和封顶是声明式的 |
| 「为什么不直接问 LLM？」 | 分值确定、互斥确定、封顶确定，交给模型只会偶尔算错且不可查 |
| 「规则抄错了怎么办？」 | 每条带 `page`，抽查可回原文；`parser_version` 变了旧页码会失效，需要重核 |
| 「附录名单为什么不做？」 | 名单是几百行动态数据，做进来是体力活；缺它时系统说 `unknown`，不说 0 分——这是诚实，不是省略 |
| 「71 分那个是怎么发现的？」 | 把规则拆成数据后跑了一遍"理论满分"，才看见。检索发现不了 |
