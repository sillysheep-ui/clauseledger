# 载体：一份文件、多个副本，只解析一个

> 这一层解决的不是"解析得准不准"，而是"同一份文件被读了两遍"。

## 一、原来的错

`ingest()` 把**页面正文**和**附件**的块拼成一个列表再切条款：

```
页面 blocks  +  附件 blocks  →  一个列表  →  split_clauses()
```

这等于默认"页面是一份、附件是另一份内容"。但多数情况下它们是**同一份文件的两种载体**：
网页版和 PDF 版。结果是同一句话在库里出现两次——

`沪人社规〔2021〕2号` 第十一条：

| 载体 | block | page | 文本 |
|---|---|---|---|
| 网页 | 53 | 无 | 同一条款 |
| 附件 PDF | 204 | 第 7 页 | 同一条款 |

下游全部为这个错误付利息：

- 条款总数虚高（**11,123** 里有 **2,524** 条是精确重复）
- 检索时同一句占掉 top-5 的两个名额
- 引用坐标时有时无（命中的可能是没有页码的那一份）
- 关系抽取时"废止"句出现两次，边跟着翻倍

## 二、模型：文件 → 载体

```
一份文件（doc_no）
 ├─ 载体 A：网页原文        sha256 …
 ├─ 载体 B：附件 PDF        sha256 …
 └─ 载体 C：附件 表格       sha256 …
```

每个载体单独解析，然后分三类处理：

| 类别 | 判定 | 处理 |
|---|---|---|
| **主副本** | 按五条规则选 | 提供正文与引用坐标 |
| **补充** | 与主副本路径重合 <0.6，且 ≥400 字、≥2 条 | 去重后并入 |
| **副本** | 路径重合 ≥0.6 且没有新增路径 | 只登记字节与 sha256 |

其中"重合但**有**新增路径"的载体按**补充**处理，只取主副本没有的路径——
网页版常多出通知抬头、附则、附件说明，直接丢会少内容。

## 三、主副本五条规则（按顺序）

1. 字数不到最全载体 60% 的，先排除（空壳页、只剩附件链接的页面）
2. 有**原生 PDF 文本层** → 选 PDF（文字准确、带页码）
3. 只有扫描件但 OCR 置信度 ≥0.85 → 选扫描件（有页码）
4. 网页正文可直接读 → 选网页（无 OCR 风险，但只有段落坐标）
5. 其余 → 取条款最多的一份

选中的理由写进 `carrier_choice.reason`，事后可核对。

## 四、结果（574 份）

| 指标 | 拼接式（旧） | 载体重建（新） |
|---|---|---|
| 条款数 | 11,123 | **8,054**（−27.6%） |
| 总字数 | 1,239,737 | **960,187**（−22.6%） |
| 同文重复条款 | 2,524 | **5** |
| 带页码条款占比 | 31.2% | **39.7%** |
| 最长条款字数 | 8,646 | **3,941** |
| 零条款文件 | 53 | 54 |
| 索引条款 | 6,604 | **6,137** |

主副本来源：页面 387 / 附件 187。

## 五、评测影响：数字下降，但不是能力退化

同一批 dev 题（official n=94）：

| 指标 | 旧索引 | 新索引 |
|---|---|---|
| hit@1 | 60.6%（50.5–70.0） | **55.3%（45.3–65.0）** |
| hit@3 | 74.5% | 70.2% |
| MRR | 0.690 | 0.639 |
| 应答率 | 90.4% | 88.3% |
| out_of_scope 拒答 | 100% | 100% |

逐题对比：**5 条变差、0 条变好**，全部集中在被去重的文档上。

变差的三类原因（逐条查过）：

1. `沪人社规〔2020〕5号`：全文只剩 3 条、361 字，覆盖率 40% 触发拒答
2. `沪人社规〔2018〕21号`：条款 156→78，金标条款从第 1 名掉到第 2 名
3. `沪人社规〔2025〕1号`：扫描件主副本，覆盖率 45% 触发拒答

其中两条是**闸门**（覆盖率 50% 阈值）在短文档上误拒，属于已知的第二类问题，
不是去重造成的直接损失。

**结论：55.3% 是去掉重复副本后的口径，60.6% 里含有"同一份文件在索引里有两份副本"
带来的排序便利。两个数都要报，不能只报高的那个。**

## 六、顺带修掉的解析缺陷

PDF 的换行是排版换行，不是段落边界。原实现一行一块，导致：

```
一、建国前参加革命工作建国后经组织批准退职且原无固定
收入的干部、生活补助费已按规…
```

`固定\n收入` 在检索时被切成两个词。`PARSER_VERSION 0.3.15` 起在页内把折行接回去
（遇到新编号、句末标点、抄送等不接）。

## 七、已知限制

- 剩余 **5 条**同文重复：来自同一载体内部的重复表述，不是两载体造成的
- 零条款文件 53→54：`沪人社规〔2025〕13号` 等表格型文件本来就没编号
- 补充载体只按"路径是否有新增"判断，同一路径下的**新增内容**不会并入
  （例如网页版把某条写得更长）——这一条要在条款级去重（L4/L5）里解决
- 主副本一旦选定，整份文件用它的坐标；混合载体（正文来自网页、附表来自 PDF）
  的坐标会在补充条款上体现为 PDF 页码，需在引用串里标载体

## 八、怎么验证这一步做对了

1. **重复消失**：`同文重复条款` 2,524 → 5
2. **内容没少**：全库字数 −22.6%，与"重复条款占比 22.7%"吻合
3. **坐标更全**：带页码条款 31.2% → 39.7%
4. **评测不吹**：5 条变差全部能指名到具体文件与原因
5. **可回滚**：新旧两份语料并存，`data/processed.carriers` 没覆盖 `data/processed`
